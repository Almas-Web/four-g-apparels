Four-G Apparels Ltd. — Modern Sourcing & Buying House Website

A modern, high-performance, and responsive multi-page corporate website built for Four-G Apparels Ltd., a premier garments buying, sourcing, and product development house based in Dhaka, Bangladesh.

🌟 Features

Modular Frontend Architecture: Built with pure Vanilla HTML5, modular CSS (variables.css, base.css, components.css, pages.css), and lightweight Vanilla JavaScript (main.js, theme.js).

Interactive Visuals & Animations: Hexagon curtain page transitions, magnetic & shine buttons, 3D tilt cards with spotlight tracking, and smooth scroll animations.

Dynamic Theme Switcher: Fully customizable multi-theme system (Navy, Red, Green, Dark) with persistent user preference storage.

Fully Responsive Navigation: Desktop navbar with glassmorphism effects and a fullscreen mobile navigation drawer with staggered reveal animations.

Comprehensive Sections: Home, About, Services, Products (Men, Ladies, Kids collections), Compliance, and an Interactive Contact/Inquiry section.

Optimized & Secure: Strict Content Security Policy (CSP), responsive image loading, and SEO-friendly meta tagging.

🚀 Getting Started Locally

To run and test this project locally on your machine:

Clone the repository:

git clone https://github.com/your-username/four-g-apparels.git
cd four-g-apparels


Run with a Local Server:

If you are using VS Code, install the Live Server extension, right-click index.html, and select "Open with Live Server".

Alternatively, if you have Node.js installed, run:

npx serve


☁️ Deployment on Vercel

This project is fully optimized for static deployment on Vercel:

Push your code to a GitHub repository.

Log in to Vercel and click "Add New Project".

Import your four-g-apparels repository.

Leave the build settings as default (Static HTML) and click Deploy.
